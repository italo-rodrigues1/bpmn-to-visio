# Third-party converter

`bpmn_to_vsdx.py` is vendored from [Mgabr90/bpmn-to-visio](https://github.com/Mgabr90/bpmn-to-visio), version 1.1.1, under the MIT License.

The Next.js API route invokes the original zero-dependency Python converter instead of approximating its VSDX output in JavaScript. This keeps the proof of concept aligned with the library being evaluated.
